# Sewar Accessories E-Commerce Website

تطبيق ويب لمتجر إلكتروني متكامل لمشروع "سوار للإكسسوارات"، تم بناؤه باستخدام تقنيات الويب الأساسية (Native PHP & Web Technologies)، حيث يشتمل المشروع على واجهة زبائن مدعومة بسلة تسوق ولوحة تحكم مخصصة لإدارة المنتجات.

---

### التقنيات المستخدمة في المشروع:
- PHP (Native): معالجة المنطق البرمجي، إدارة الجلسات (Sessions)، والربط المباشر مع قاعدة البيانات.
- MySQL: بناء واستعلام قاعدة بيانات المنتجات والعمليات.
- JavaScript: إضافة التفاعلية للواجهات وتأكيد عمليات الإضافة للسلة.
- HTML5 & CSS3: بناء الهيكل وتنسيق الواجهات عبر ملفات نمط (CSS) منفصلة.

---

### هيكلية المشروع وتفاصيل التنفيذ:
- **واجهة الزبائن (Customer Interface):** تتيح للمستخدمين تصفح قائمة الإكسسوارات، استعراض صور المنتجات وتفاصيلها، وإضافة المنتجات إلى سلة التسوق.
- **سلة التسوق (Shopping Cart):** إدارة عناصر السلة، احتساب التكلفة الإجمالية، وتجهيز طلبات الشراء.
- **لوحة التحكم (Admin Panel):** صفحة خاصة بإدارة المتجر تتيح إضافة منتجات جديدة، تعديل البيانات الحالية، وحذف المنتجات (CRUD Operations).
- **تنسيق الملفات:** فصل ملفات الـ CSS والـ JavaScript لضمان تنظيم الكود، مع وجود مجلد `images` لتخزين وعرض الصور بشكل ديناميكي.

---

### مميزات التطبيق الأساسية:
- عرض واجهة متجر تفاعلية ومخصصة لتصفح الزبائن.
- نظام سلة تسوق لإضافة وإدارة المنتجات المختارة.
- لوحة تحكم متكاملة لإدارة كافة عمليات المنتجات.
- ربط واستعلام البيانات مباشرة عبر MySQL.
- تنظيم استدعاء الصور والملفات البرمجية محلياً.

---

### كيفية تشغيل المشروع محلياً (Local Setup):

1. Clone the repository:
   ```bash
   git clone [https://github.com/sondosghr/Sewar-Accessories-Store.git](https://github.com/sondosghr/Sewar-Accessories-Store.git)
  2.قل مجلد المشروع إلى مجلد السيرفر المحلي:

في بيئة XAMPP: ضع المجلد داخل htdocs.

3.التأكد من وجود مجلد images وكافة ملفات الـ PHP والـ CSS والـ JS داخل مجلد المشروع.

4.إعداد قاعدة البيانات:

افتح phpMyAdmin وأنشئ قاعدة بيانات جديدة فارغة باسم sewar_db.

قم بتعديل بيانات الاتصال بقاعدة البيانات في ملف index.php إن لزم الأمر (سيقوم الكود بإنشاء الجداول المطلوبة تلقائياً عند التشغيل).

5.تشغيل المشروع:

افتح المتصفح وانتقل إلى الرابط الرئيسي للمتجر (واجهة الزبائن):
http://localhost/[YOUR_FOLDER_NAME]/index.php
ملاحظة: قم باستبدال [YOUR_FOLDER_NAME] باسم مجلد المشروع الذي وضعته داخل htdocs (مثلاً: Sewar-Accessories-Store).
